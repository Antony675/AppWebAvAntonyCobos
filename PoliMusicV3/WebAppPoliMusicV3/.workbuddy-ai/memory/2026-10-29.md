# 2026-10-29

## Implementación de Song (EntityLayer / DAL / BLL) + Song.aspx

Arquitectura de 4 capas en .NET Framework 4.8 (Web Forms), solución `SlnAppPoliMusic.slnx`:

- `EntityLayer.PoliMusicV3/Song.cs` — POCO con solo propiedades auto-implementadas: `ID`, `SongName`, `SongPath`, `Plays` (mapea 1:1 con `TBL_SONG`: ID_SONG, SONG_NAME, SONG_PATH, PLAYS).
- `DAL.PoliMusicV3/Song.cs` — conexión ADO.NET con `SqlConnection`/`SqlCommand` y parámetros. Métodos: `Save`, `Read`, `GetById`, `Update`, `Delete`, `CheckExistSong`, `RegisterPlay`. Sigue el patrón de `DAL.User` (ctor recibe la cadena de conexión).
- `BLL.PoliMusicV3/Song.cs` — ctor recibe la cadena de conexión y delega al DAL; añade `ValidationsRequired` (nombre obligatorio, máx 50 chars, ruta .mp3 obligatoria), `ValidationsDuplicated`, mapeo `DataTable -> List<EntityLayer.Song>` y `RegisterPlay`.
- `WebAppPoliMusicV3/Song.aspx(.cs/.designer.cs)` — lista canciones con `Repeater`, reproductor fijo inferior con `<audio>` + JS, filtro en vivo por título, columna duración leída de los metadatos del mp3. Saluda con `Hola, "usuario"` usando `Session[Constants.USER]` (fallback a `Page.User.Identity.Name`).

## Decisiones / convenciones

- El nombre de la clase de página es `Song` (igual que el `Song` de las otras capas), por eso en el code-behind los tipos se referencian siempre con el nombre completo (`EntityLayer.PoliMusicV3.Song`, `BLL.PoliMusicV3.Song`).
- Conteo de reproducciones: `[WebMethod] public static int RegisterPlay(int)` + `EnablePageMethods="true"` en el `ScriptManager` de `Site.Master`; se llama por AJAX para no cortar la reproducción con un postback.
- Los `<%# %>` que emiten símbolos con `<`/`>` deben pasar por `Server.HtmlEncode` (el glifo `</>` se perdía como etiqueta HTML).
- Tema visual: morado satinado (gradiente `#4c1d95 -> #6d28d9 -> #3b1266` + brillo diagonal), estética de código (Consolas, rutas `~/songFiles/...`, glifos `{ } </> && => [ ]`). Estilos inline en la propia página, restyling del navbar del master vía `body` scope.
- `SongFiles/`: solo existía `bensound-adventure.mp3`; se copió con los nombres que espera el seed de `BDD_PoliMusic.sql` (`bensound-dreams/energy/scifi/tomorrow.mp3`) para que las 5 filas reproduzcan. Son duplicados temporales, reemplazar por los audios reales.
- `Site.Master`: se corrigió la etiqueta mal cerrada `</li` del enlace "Canciones".
